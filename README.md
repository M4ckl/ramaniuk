# M.RAMANIUK Portfolio Website v3

Welcome to my personal portfolio website! This project showcases my skills, projects, and experience as a mobile developer, with a focus on iOS development.

## About

This portfolio website is designed to present my work and skills in a clean, modern, and interactive way. It includes:

- An **About Me** section with my personal introduction.
- A **Projects** modal displaying my applications, their design, tech stack, and status.
- A **Skills** modal showcasing technologies I work with.
- Links to my **LinkedIn, GitHub, Facebook, and Telegram** profiles.

The design focuses on usability, responsiveness, and smooth interactions, including video backgrounds and interactive modals.

## Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Design:** Figma

## Last Updates (Version 3)

- **Minimal redesign:** Text-only editorial layout with the Boska serif, no rounded cards and no theme switcher.
- **Skills sphere:** The skills are now a 3D sphere of words you can drag to turn.
- **Smooth motion:** Letter-by-letter name reveal, scroll-lit about text and staggered section entrances.

## Version 2

- **Interactive 3D Sphere:** Replaced the static 2D skills circle with a dynamic, interactive 3D skills sphere.
- **Theme Switcher:** Implemented a seamless Light/Dark mode button to improve accessibility and user experience.
- **Micro-animations:** Added refined, fluid micro-animations across UI elements for a more polished "Apple-like" feel.
- **Enhanced Interactivity:** Upgraded overall layout responsiveness and improved user interactions throughout the site.
